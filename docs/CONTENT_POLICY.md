# 素材边界

本项目把“可以访问”与“可以再分发”视为两件事。

## 不进入公开仓库的内容

- CET-6 历年听力录音、试题 PDF、听力原文、答案及其他可能受版权保护的原始材料。
- 包含上述材料的内置音频 APK。
- 来源不明的网盘包、培训机构打包材料、公众号下载包。

## 本地私有构建

个人学习场景可以在本机把已经合法取得的音频放入应用。构建脚本只读取本地路径，不抓取链接，不会把文件上传到网络。

## 公开发布前

若要公开发布完整 APK 或演示视频，请逐项确认：

1. 录音的复制、改编和信息网络传播权；
2. 试题、脚本、译文和封面素材的授权；
3. 仓库许可证与素材许可证是否分开；
4. 来源、日期、SHA-256 与权利状态是否可审计。

在授权不明确时，只发布源代码、示例数据和不含第三方音频的构建说明。
